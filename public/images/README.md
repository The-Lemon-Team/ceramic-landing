# Logo Instructions

Поместите файл логотипа в эту папку с именем `logo.png` или `logo.svg`.

Поддерживаемые форматы:
- PNG (рекомендуется)
- SVG

Размер логотипа должен быть примерно 40x40px или больше (будет автоматически масштабирован).

Если вы используете другой формат или имя файла, обновите пути в:
- `components/Navbar.tsx`
- `components/Footer.tsx`
